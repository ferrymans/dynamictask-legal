常见问题

Q:如何取消订阅?

iPhone → 设置 → 你的 Apple ID → 订阅 → DynamicTask Pro → 取消订阅。试用期内取消不会扣费。

Q:数据丢失怎么办?

  1. 若 iCloud 同步开启,在同一 Apple ID 的另一台设备装 App,数据自动拉回
  2. 检查 iOS 设置 → Apple ID → iCloud → 灵动代办 是否启用
  3. 仍未恢复,联系 pixelyang@icloud.com

Q:灵动岛 / Live Activity 不显示?

  1. 系统设置 → 灵动代办 → 「允许 Live Activities」是否开启
  2. App 内 设置 → 「灵动岛」开关是否打开
  3. 仅当日有未完成代办或番茄钟正运行时才显示
  4. iOS Live Activity 有 ~12 小时上限,App 回前台时会自动重新拉起

Q:子任务能同步到 iOS 系统提醒事项吗?

不能。iOS 26 EventKit 公开 API 暂不支持真子任务(Apple 内部用 SQLite 关系表实现,未对外暴露)。我们的同步覆盖标题 / 描述 / 日期 / 通知,但不含子任务。

Q:启动页为什么只显示英文 "DynamicTask"?

iOS 系统不支持启动页文字本地化(预渲染缓存机制,详见 Apple Developer Forums thread 86567)。所有用户看到的都是英文品牌名,这是 Apple 系统的设计限制。

Q:iCloud 同步看起来没生效?

  1. 确认设备已登录 iCloud 且 iCloud Drive 开启
  2. iOS 设置 → Apple ID → iCloud → 灵动代办 开关需启用
  3. App 内 设置 页有 iCloud 同步状态指示
  4. 跨设备同步是异步的,可能 30 秒+ 延迟,大量数据可能数分钟

Q:恢复购买在哪?

设置 → 订阅开通 → ProSheet 弹窗底部 →「恢复购买」。换设备 / 重装 App / 切 Apple ID 后,从这里拉回历史订阅与永久购买 entitlement。

Q:家庭共享如何使用?

家庭组织者购买永久买断 / 订阅后,在 设置 → Apple ID → 家庭共享 内启用「与家庭共享」。家庭成员的设备会自动激活 Pro,设置页 Pro 徽章显示「家庭共享」。

FAQ

Q: How do I cancel my subscription?

iPhone → Settings → Your Apple ID → Subscriptions → DynamicTask Pro → Cancel Subscription. Cancelling during the free trial costs nothing.

Q: My data is missing — how do I recover it?

  1. If iCloud sync was on, install the app on another device with the same Apple ID — data will pull in automatically.
  2. Check iOS Settings → Apple ID → iCloud → DynamicTask is enabled.
  3. Still missing? Email pixelyang@icloud.com.

Q: Dynamic Island / Live Activity isn't showing.

  1. System Settings → DynamicTask → "Allow Live Activities" enabled.
  2. In-app Settings → "Dynamic Island" toggle on.
  3. Shows only when there's an unfinished todo today or a Pomodoro is running.
  4. iOS Live Activity has a ~12-hour limit; the app restarts it when you bring it to the foreground.

Q: Can subtasks sync to iOS Reminders?

No. iOS 26 EventKit's public API doesn't expose real subtasks (Apple uses internal SQLite relations not exposed externally). Sync covers title, notes, date, and alarm — not subtasks.

Q: Why is the launch screen always in English?

iOS doesn't support launch screen text localization (pre-rendered cache mechanism, see Apple Developer Forums thread 86567). All users see the English brand name — this is an Apple platform limitation.

Q: iCloud sync doesn't seem to work?

  1. Confirm device is signed in to iCloud with iCloud Drive enabled.
  2. iOS Settings → Apple ID → iCloud → DynamicTask toggle must be on.
  3. In-app Settings page shows iCloud sync status indicator.
  4. Cross-device sync is asynchronous — may take 30s+, larger data sets may take minutes.

Q: Where is "Restore Purchases"?

Settings → Subscribe → ProSheet popup → bottom row "Restore Purchases". Use this after switching devices, reinstalling, or changing Apple ID to recover existing subscriptions and lifetime purchases.

Q: How does Family Sharing work?

The family organizer buys the lifetime / subscription, then enables "Share with Family" via Settings → Apple ID → Family Sharing. Family members' devices auto-activate Pro, and the Settings page Pro badge shows "Family".
