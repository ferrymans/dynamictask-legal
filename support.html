FAQ

Q: How do I cancel my subscription?

iPhone → Settings → Your Apple ID → Subscriptions → DynamicTask Pro → Cancel Subscription. Cancelling during the free trial costs nothing.

Q: Dynamic Island / Live Activity isn't showing.

  1. System Settings → DynamicTask → "Allow Live Activities" enabled.
  2. In-app Settings → "Dynamic Island" toggle on.
  3. Shows only when there's an unfinished todo today or a Pomodoro is running.
  4. iOS Live Activity has a ~12-hour limit; the app restarts it when you bring it to the foreground.

Q: Can subtasks sync to iOS Reminders?

No. iOS 26 EventKit's public API doesn't expose real subtasks (Apple uses internal SQLite relations not exposed externally). Sync covers title, notes, date, and alarm — not subtasks.

Q: Why is the launch screen always in English?

iOS doesn't support launch screen text localization (pre-rendered cache mechanism, see Apple Developer Forums thread 86567). All users see the English brand name — this is an Apple platform limitation.

Q: iCloud sync doesn't seem to work?

  1. Confirm device is signed in to iCloud with iCloud Drive enabled.
  2. iOS Settings → Apple ID → iCloud → DynamicTask toggle must be on.
  3. In-app Settings page shows iCloud sync status indicator.
  4. Cross-device sync is asynchronous — may take 30s+, larger data sets may take minutes.
  5. Your data lives in your private iCloud — sign in to the same Apple ID on any device and it syncs back.

Q: Where is "Restore Purchases"?

Settings → Subscribe → ProSheet popup → bottom row "Restore Purchases". Use this after switching devices, reinstalling, or changing Apple ID to recover existing subscriptions and lifetime purchases.

Q: How does Family Sharing work?

The family organizer buys the lifetime / subscription, then enables "Share with Family" via Settings → Apple ID → Family Sharing. Family members' devices auto-activate Pro, and the Settings page Pro badge shows "Family".

よくある質問

Q:サブスクリプションを解約するには?

iPhone → 設定 → Apple ID → サブスクリプション → DynamicTask Pro → サブスクリプションをキャンセル。無料トライアル中の解約は無料です。

Q:Dynamic Island / Live Activity が表示されません。

  1. システム設定 → DynamicTask →「Live Activitiesを許可」が ON になっているか
  2. App 内 設定 →「Dynamic Island」スイッチが ON になっているか
  3. 当日に未完了の ToDo があるか、ポモドーロが実行中の場合のみ表示されます
  4. iOS Live Activity には約 12 時間の上限があり、App をフォアグラウンドに戻すと再起動されます

Q:サブタスクは iOS リマインダーに同期できますか?

できません。iOS 26 EventKit の公開 API は本当のサブタスクをサポートしていません(Apple は内部の SQLite リレーションで実装しており、外部には公開されていません)。同期はタイトル / メモ / 日付 / アラームをカバーしますが、サブタスクは含まれません。

Q:起動画面が常に英語の "DynamicTask" になっているのはなぜですか?

iOS は起動画面のテキストのローカライズに対応していません(プリレンダリングのキャッシュ機構による、Apple Developer Forums thread 86567 を参照)。すべてのユーザーに英語のブランド名が表示されます — これは Apple プラットフォームの仕様です。

Q:iCloud 同期が反映されないようです。

  1. デバイスが iCloud にサインインし、iCloud Drive が有効になっていることを確認してください。
  2. iOS 設定 → Apple ID → iCloud → DynamicTask スイッチが ON になっている必要があります。
  3. App 内 設定 画面に iCloud 同期状態のインジケーターがあります。
  4. デバイス間の同期は非同期で、30 秒以上、大規模なデータでは数分かかる場合があります。
  5. データはあなたのプライベート iCloud に保存されています — 任意のデバイスで同じ Apple ID にサインインすれば同期されます。

Q:「購入の復元」はどこにありますか?

設定 → サブスクリプション開通 → ProSheet の下部 →「購入を復元」。デバイス変更 / 再インストール / Apple ID 切り替え後は、ここから既存のサブスクリプションと買い切り購入を復元できます。

Q:ファミリー共有はどう使いますか?

ファミリー共有の管理者が買い切り版 / サブスクリプションを購入後、設定 → Apple ID → ファミリー共有 で「ファミリーと共有」を有効にします。家族のデバイスでは Pro が自動で有効化され、設定画面の Pro バッジには「ファミリー共有」と表示されます。

Q: 구독을 어떻게 취소하나요?

iPhone → 설정 → 본인 Apple ID → 구독 → DynamicTask Pro → 구독 취소. 무료 체험 기간 중 취소하면 요금이 청구되지 않습니다.

Q: Dynamic Island / Live Activity가 표시되지 않습니다.

  1. 시스템 설정 → DynamicTask → 'Live Activities 허용'이 켜져 있는지 확인하세요.
  2. 앱 내 설정 → 'Dynamic Island' 스위치가 켜져 있는지 확인하세요.
  3. 오늘 미완료된 할 일이 있거나 뽀모도로가 실행 중일 때만 표시됩니다.
  4. iOS Live Activity는 약 12시간 제한이 있으며, 앱을 다시 포그라운드로 가져오면 재시작됩니다.

Q: 하위 작업을 iOS 미리 알림에 동기화할 수 있나요?

아니요. iOS 26 EventKit 공개 API는 실제 하위 작업을 제공하지 않습니다(Apple은 내부 SQLite 관계로 구현하며 외부에 공개하지 않음). 동기화는 제목 / 노트 / 날짜 / 알람을 다루지만 하위 작업은 포함되지 않습니다.

Q: 시작 화면이 왜 항상 영어 "DynamicTask"로 표시되나요?

iOS는 시작 화면 텍스트의 현지화를 지원하지 않습니다(미리 렌더링된 캐시 메커니즘, Apple Developer Forums thread 86567 참조). 모든 사용자에게 영어 브랜드 이름이 표시됩니다 — 이는 Apple 플랫폼의 제한입니다.

Q: iCloud 동기화가 작동하지 않는 것 같습니다.

  1. 기기가 iCloud에 로그인되어 있고 iCloud Drive가 활성화되어 있는지 확인하세요.
  2. iOS 설정 → Apple ID → iCloud → DynamicTask 스위치가 켜져 있어야 합니다.
  3. 앱 내 설정 페이지에 iCloud 동기화 상태 표시가 있습니다.
  4. 기기 간 동기화는 비동기적이며 30초 이상, 대용량 데이터는 몇 분이 걸릴 수 있습니다.
  5. 데이터는 본인의 비공개 iCloud에 보관됩니다 — 어떤 기기에서든 동일한 Apple ID로 로그인하면 동기화됩니다.

Q: '구입 복원'은 어디에 있나요?

설정 → 구독 시작 → ProSheet 하단 → '구입 복원'. 기기 변경 / 앱 재설치 / Apple ID 변경 후 기존 구독과 평생 구입 entitlement를 복원할 때 사용하세요.

Q: 가족 공유는 어떻게 사용하나요?

가족 공유 관리자가 평생 / 구독을 구매한 후 설정 → Apple ID → 가족 공유 에서 '가족과 공유'를 활성화합니다. 가족 구성원의 기기에서는 Pro가 자동으로 활성화되고, 설정 페이지의 Pro 배지는 '가족 공유'로 표시됩니다.

Häufige Fragen

F: Wie kündige ich mein Abonnement?

iPhone → Einstellungen → Apple-ID → Abonnements → DynamicTask Pro → Abonnement kündigen. Eine Kündigung während der kostenlosen Testphase ist kostenlos.

F: Dynamic Island / Live-Aktivität wird nicht angezeigt.

  1. Systemeinstellungen → DynamicTask → „Live-Aktivitäten erlauben" aktiviert.
  2. In-App-Einstellungen → „Dynamic Island"-Schalter ein.
  3. Wird nur angezeigt, wenn heute eine offene Aufgabe vorhanden ist oder ein Pomodoro läuft.
  4. iOS Live-Aktivitäten haben ein Limit von ca. 12 Stunden; die App startet sie neu, sobald sie wieder in den Vordergrund kommt.

F: Können Teilaufgaben mit iOS Erinnerungen synchronisiert werden?

Nein. Die öffentliche EventKit-API von iOS 26 bietet keine echten Teilaufgaben (Apple verwendet interne SQLite-Beziehungen, die nicht extern verfügbar sind). Die Synchronisierung deckt Titel, Notizen, Datum und Wecker ab, aber keine Teilaufgaben.

F: Warum ist der Startbildschirm immer auf Englisch?

iOS unterstützt keine Lokalisierung von Texten auf dem Startbildschirm (vorgerenderter Cache-Mechanismus, siehe Apple Developer Forums Thread 86567). Alle Benutzer sehen den englischen Markennamen — dies ist eine Plattformbeschränkung von Apple.

F: Die iCloud-Synchronisierung funktioniert anscheinend nicht?

  1. Stellen Sie sicher, dass das Gerät bei iCloud angemeldet ist und iCloud Drive aktiviert ist.
  2. iOS-Einstellungen → Apple-ID → iCloud → Schalter „DynamicTask" muss aktiviert sein.
  3. Die In-App-Einstellungsseite zeigt einen iCloud-Synchronisierungsstatus an.
  4. Die geräteübergreifende Synchronisierung erfolgt asynchron — sie kann 30 Sekunden oder länger dauern, größere Datenmengen können mehrere Minuten in Anspruch nehmen.
  5. Ihre Daten leben in Ihrer privaten iCloud — melden Sie sich auf einem beliebigen Gerät mit derselben Apple-ID an, und sie werden zurück synchronisiert.

F: Wo finde ich „Käufe wiederherstellen"?

Einstellungen → Abonnement → ProSheet-Popup → unten „Käufe wiederherstellen". Verwenden Sie diese Option nach Gerätewechsel, Neuinstallation oder Apple-ID-Wechsel, um vorhandene Abonnements und Einmalkäufe wiederherzustellen.

F: Wie funktioniert die Familienfreigabe?

Der Familienorganisator kauft die Einmal-Lizenz / das Abonnement und aktiviert dann „Mit Familie teilen" über Einstellungen → Apple-ID → Familienfreigabe. Auf den Geräten der Familienmitglieder wird Pro automatisch aktiviert, und der Pro-Hinweis auf der Einstellungsseite zeigt „Familie" an.

FAQ

Q : Comment annuler mon abonnement ?

iPhone → Réglages → Identifiant Apple → Abonnements → DynamicTask Pro → Annuler l'abonnement. L'annulation pendant la période d'essai gratuit ne coûte rien.

Q : Dynamic Island / Activité en direct ne s'affiche pas.

  1. Réglages système → DynamicTask → « Autoriser les activités en direct » activé.
  2. Dans l'app, Réglages → bascule « Dynamic Island » sur ON.
  3. Ne s'affiche que lorsqu'il y a une tâche non terminée aujourd'hui ou qu'un Pomodoro est en cours.
  4. Les activités en direct iOS ont une limite d'environ 12 heures ; l'app les relance quand vous la repassez au premier plan.

Q : Les sous-tâches peuvent-elles se synchroniser avec Rappels d'iOS ?

Non. L'API publique EventKit d'iOS 26 ne propose pas de véritables sous-tâches (Apple utilise des relations SQLite internes, non exposées). La synchronisation couvre le titre, les notes, la date et l'alarme — pas les sous-tâches.

Q : Pourquoi l'écran de lancement est-il toujours en anglais ?

iOS ne prend pas en charge la localisation du texte de l'écran de lancement (mécanisme de cache pré-rendu, voir Apple Developer Forums thread 86567). Tous les utilisateurs voient le nom de marque en anglais — c'est une limitation de la plate-forme Apple.

Q : La synchronisation iCloud ne semble pas fonctionner ?

  1. Vérifiez que l'appareil est connecté à iCloud et que iCloud Drive est activé.
  2. Réglages iOS → Identifiant Apple → iCloud → la bascule DynamicTask doit être activée.
  3. La page Réglages de l'app affiche un indicateur d'état de la synchronisation iCloud.
  4. La synchronisation entre appareils est asynchrone — elle peut prendre plus de 30 secondes, voire plusieurs minutes pour de grands volumes.
  5. Vos données vivent dans votre iCloud privé — connectez-vous au même identifiant Apple sur n'importe quel appareil et elles se synchroniseront.

Q : Où se trouve « Restaurer les achats » ?

Réglages → S'abonner → fenêtre ProSheet → ligne du bas « Restaurer les achats ». À utiliser après un changement d'appareil, une réinstallation ou un changement d'identifiant Apple pour récupérer les abonnements et achats à vie existants.

Q : Comment fonctionne le Partage familial ?

L'organisateur familial achète la licence à vie / l'abonnement, puis active « Partager avec la famille » via Réglages → Identifiant Apple → Partage familial. Pro s'active automatiquement sur les appareils des membres de la famille, et l'insigne Pro sur la page Réglages affiche « Famille ».

  3. La página de Ajustes en la app muestra un indicador de estado de sincronización con iCloud.
  4. La sincronización entre dispositivos es asíncrona — puede tardar 30 s o más; los conjuntos de datos grandes pueden tardar minutos.

Частые вопросы

В: Как отменить подписку?

iPhone → Настройки → Ваш Apple ID → Подписки → DynamicTask Pro → Отменить подписку. Отмена во время бесплатного пробного периода — бесплатно.

В: Dynamic Island / «Активность в реальном времени» не отображается.

  1. Системные настройки → DynamicTask → «Разрешить активности в реальном времени» включено.
  2. В приложении: Настройки → переключатель «Dynamic Island» включён.
  3. Отображается только при наличии незавершённой задачи на сегодня или запущенного Pomodoro.
  4. iOS Live Activity имеет ограничение около 12 часов; приложение перезапускает её при возврате на передний план.

В: Можно ли синхронизировать подзадачи с «Напоминаниями» iOS?

Нет. Публичный API EventKit в iOS 26 не предоставляет настоящих подзадач (Apple использует внутренние связи SQLite, не выставленные наружу). Синхронизация охватывает заголовок, заметки, дату и будильник — без подзадач.

В: Почему стартовый экран всегда на английском «DynamicTask»?

iOS не поддерживает локализацию текста на стартовом экране (механизм предварительного кеширования, см. Apple Developer Forums thread 86567). Все пользователи видят бренд на английском — это ограничение платформы Apple.

В: Синхронизация iCloud не работает?

  1. Убедитесь, что устройство вошло в iCloud и включён iCloud Drive.
  2. Настройки iOS → Apple ID → iCloud → переключатель DynamicTask должен быть включён.
  3. На странице Настройки в приложении есть индикатор состояния синхронизации iCloud.
  4. Синхронизация между устройствами асинхронна — может занять более 30 с, а при больших объёмах данных — несколько минут.
  5. Ваши данные хранятся в вашем личном iCloud — войдите с тем же Apple ID на любом устройстве, и они синхронизируются обратно.

В: Где «Восстановить покупки»?

Настройки → Подписка → всплывающее окно ProSheet → нижняя строка «Восстановить покупки». Используйте после смены устройства, переустановки или смены Apple ID, чтобы вернуть существующие подписки и пожизненные покупки.

В: Как работает Семейный доступ?

Организатор семьи покупает пожизненную версию / подписку, затем включает «Поделиться с семьёй» в Настройки → Apple ID → Семейный доступ. На устройствах членов семьи Pro активируется автоматически, а значок Pro на странице Настройки показывает «Семейный доступ».
