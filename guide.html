5-minute onboarding for DynamicTask — core philosophy, the four-layer model, and main features.

Not just another todo list

DynamicTask's core idea: upgrade your todos from a flat list to a four-layer life model.

Regular todo apps let you write "what to do today"; DynamicTask asks you to think clearly:

  • Dimension: How is your life partitioned? (Eisenhower matrix, or custom)
  • Goal: What do you want to achieve? (Read books / Get fit / Learn an instrument)
  • Plan: To reach the goal, what activities are required? (3× strength training per week)
  • Todo: What specific step today? (Bench press 4×8)

With this structure, your todos are no longer a pile of tasks — they form a clear path through life.

The four layers explained

1. Dimension — life reference frame.
Four defaults based on the Eisenhower matrix: High Importance / Low Importance / High Urgency / Low Urgency. You can add custom dimensions (pick a color + name) from the "New Goal" sheet. Each goal can bind multiple dimensions.
2. Goal — what you want to achieve.
Examples: "Pass the architect exam", "Read 30 books", "Learn Hotel California on guitar". Each goal binds a color (11 presets + system color picker) which cascades down to its todos. Dimensions are optional — bind them to organize goals by life area. A "Default Goal" (bound to High Importance + High Urgency) ships with the app for users who don't want to categorize.
3. Plan — activities required to reach a goal.
Example: Under the goal "Read 30 books", a plan = "2 classic novels per month". Each plan has an icon (from 800+ library) and a completion criterion (free text). A plan itself isn't a todo — you don't "do" the plan, you do the todos under it.
4. Todo — actionable steps.
Example: Under "2 classic novels per month", a todo = "100 Years of Solitude, Chapter 3". Must belong to a plan. Can have 1–4 subtasks; can have a scheduled time (start/end window, draggable ring). Completion triggers a satisfying micro-animation.

Main interfaces

Home (Todos)

First tab in the bottom capsule nav, default entry. Today's todos grouped into Pinned → In Progress → Completed.

  • Pull-down gesture: cycle list → week calendar → month calendar
  • Top-left calendar icon: tap to cycle the same three states
  • Historical date rule: yesterday's and earlier unfinished todos auto-migrate to today; historical dates only show completed
  • Row interactions: tap row → edit sheet; tap ring → mark complete; long-press drag → reorder, with the capsule morphing into "Pin / Delete" zones

1–3 colored dots under each calendar date mark that day's top todos (toggleable in Settings).

Goals

Second tab. Horizontal tabs at the top list all goals with a trailing + for new ones. Selecting a goal reveals its plans below (icon + plan name + completion criterion). Long-press a plan to edit/delete.

Statistics

Third tab. Streak heatmap (GitHub contributions style) + per-goal progress cards (weekly/monthly activity). Top-right → opens Inspiration — ideas you want to do but haven't formalized; can be promoted to real goals.

Settings

Fourth tab. Theme / accent color / Pomodoro durations / Dynamic Island toggle / iCloud sync status / Subscribe / Language / Help / Feedback / Promotion / Share / Rate.

Pomodoro

Fifth tab (special). Doesn't switch pages — overlays on the current page. Center: large countdown. Top: two pills toggle Focus / Rest (default 45 / 5 min, customizable). Bottom: ▶ Start / ⏸ Pause / ↻ Reset. The Dynamic Island mirrors the countdown and progress ring; Lock Screen also shows a Pomodoro card. The bottom capsule morphs into a back button during sessions.

Key features

Sync with iOS Reminders

The Todo Time section has a multi-color calendar icon (calendar.badge) on the right: gray dot = unsynced; green dot = synced. Tap gray: first time prompts for permission, then immediately syncs the current todo to the default Reminders list. The system will fire a notification at the scheduled time. Tap green: removes from Reminders.

⚠ Deleting a todo in DynamicTask cascades to delete the corresponding system reminder (one delete clears both); clearing the scheduled time auto-unsyncs.

iCloud sync

Enabled automatically on first launch (no prompt). All data (dimensions/goals/plans/todos/inspirations) syncs across devices via your private iCloud database. Conflict policy: last-write wins. Works as long as your iPhone is signed in to iCloud with iCloud Drive enabled — no extra setup.

Widget (Home Screen)

Streak heatmap: same view as the Statistics page streak, available in small / medium / large sizes. Long-press the Home Screen → Add Widget → search "DynamicTask".

Live Activity (Dynamic Island + Lock Screen)

Auto-switches between two modes:

  • Todo overview: when no Pomodoro is running, the Dynamic Island shows the first unfinished todo + overall progress; the Lock Screen card shows the top 3 unfinished todos
  • Pomodoro: during a Pomodoro session, shows countdown and progress ring

Long-press the Dynamic Island to expand the full card.

Subscription

Four tiers. Actual prices are shown live by the App Store:

  • Trial Member: 7-day free trial, auto-converts to monthly on expiry
  • Monthly
  • Annual: better value than monthly
  • Lifetime: includes all future features, identical to subscriptions except duration ("Best deal" badge)

The three paid tiers (monthly / annual / lifetime) offer identical features — only the duration differs. Monthly and annual share the same Subscription Group, so you can upgrade/downgrade freely in iOS subscription settings (Apple auto-prorates refunds). Trial eligibility is determined per Apple ID; each Apple ID can use the trial once per subscription group. Cancel anytime via System Settings → Apple ID → Subscriptions; cancelling during trial costs nothing.

After switching devices / reinstalling: Settings → Subscribe → Restore Purchases pulls back all historical purchases.

Privacy

DynamicTask collects zero user data to our servers. All data is stored locally + synced via your private iCloud database; only you and Apple can see it. See the Privacy Policy for details.

Feedback & contact

Bug reports / feature requests / business inquiries: pixelyang@icloud.com. You can also use Settings → Feedback inside the app to compose an email directly. For FAQs and troubleshooting, see Support.

DynamicTask のコア理念は:ToDo を「平らなリスト」から「人生の 4 層モデル」へ昇華させること。

普通の ToDo アプリは「今日何をするか」を書き留めるだけですが、DynamicTask では次のように整理して考えます:

  • 次元 (Dimension):人生をいくつの軸で分けるか?(重要度・緊急度の 4 象限、または独自設定)

  • 計画 (Plan):目標達成のために何をするか?(週 3 回の筋トレ)
  • ToDo:今日の具体的な一歩は?(ベンチプレス 4×8)

この構造があれば、ToDo は単なる作業の山ではなく、人生の明確な道筋になります。

4 層の解説

1. 次元 (Dimension) — 人生の参照軸。
Eisenhower マトリクスに基づく 4 つの初期値:重要度高 / 重要度低 / 緊急度高 / 緊急度低。「目標を追加」シートからカスタム次元を追加できます(色 + 名前を選択)。各目標は複数の次元にバインドできます。
2. 目標 (Goal) — 達成したいこと。
例:「建築士試験に合格する」「30 冊の本を読む」「ホテル・カリフォルニアをギターで弾けるようになる」。各目標は色を 1 つバインドし(11 種プリセット + システムカラーピッカー)、その色は下位の ToDo まで染色されます。次元は任意で、人生の領域別に整理したい場合にバインドします。分類を望まないユーザー向けに「デフォルト目標」(重要度高 + 緊急度高にバインド)が初期搭載されています。
3. 計画 (Plan) — 目標達成のために必要な活動。
例:目標「30 冊の本を読む」の下の計画 = 「毎月 2 冊の古典文学」。各計画はアイコン(800+ のライブラリから選択)と達成基準(自由テキスト)を持ちます。計画自体は ToDo ではありません — 行うのは計画の下の ToDo です。
4. ToDo — 実行可能なアクション。
例:計画「毎月 2 冊の古典文学」の下の ToDo = 「『百年の孤独』第 3 章」。必ず計画に紐づきます。1〜4 個のサブタスクを追加可能、予定時刻を設定可能(開始/終了の時間帯、ドラッグ可能なリング)。完了時には心地よいマイクロアニメーションが再生されます。

主な画面

ホーム(ToDo)

下部カプセルナビの 1 つ目のタブ、デフォルトのエントリー。今日の ToDo は ピン留め → 進行中 → 完了 の 3 セクションに分類されます。

  • 下方向スワイプ:リスト → 週カレンダー → 月カレンダーを順に切り替え
  • 左上のカレンダーアイコン:タップで同じ 3 つの状態を切り替え
  • 過去日付のルール:昨日以前の未完了 ToDo は自動で今日に移行;過去日付では完了済みのみ表示
  • 行のインタラクション:行をタップ → 編集シート;リングをタップ → 完了マーク;長押しドラッグ → 並べ替え。カプセルは「ピン / 削除」ゾーンに変形します。

各カレンダー日付の下に 1〜3 個の色付きドットが表示され、その日の主要 ToDo を示します(設定で切り替え可能)。

計画

2 つ目のタブ。上部の水平タブにすべての目標が並び、末尾の + で新規目標。目標を選択すると下にその計画一覧が表示されます(アイコン + 計画名 + 達成基準)。計画を長押しすると編集 / 削除。

統計

3 つ目のタブ。連続記録のヒートマップ(GitHub の contributions 風)+ 目標ごとの進捗カード(週次/月次のアクティビティ)。右上の → で ひらめきページへ — まだ正式化していないアイデア。正式な目標に昇格できます。

設定

4 つ目のタブ。テーマ / アクセントカラー / ポモドーロ時間 / Dynamic Island スイッチ / iCloud 同期状況 / サブスクリプション / 言語 / ヘルプ / フィードバック / プロモーション / 共有 / 評価。

ポモドーロ

5 つ目のタブ(特殊)。タップしてもページは切り替わらず、現在のページに重ねて表示されます。中央:大きなカウントダウン。上部:2 つの pill で 集中 / 休憩 を切り替え(初期値 45 / 5 分、カスタマイズ可)。下部:▶ 開始 / ⏸ 一時停止 / ↻ リセット。Dynamic Island がカウントダウンと進捗リングを連動表示し、ロック画面にもポモドーロカードが表示されます。セッション中、下部カプセルは戻るボタンに変形します。

主要機能

iOS リマインダーとの同期

ToDo 時刻セクションの右側にマルチカラーのカレンダーアイコン(calendar.badge)があります:灰色のドット = 未同期;緑のドット = 同期済。灰色をタップ:初回は許可を要求し、許可後は現在の ToDo を即座にシステムのデフォルトのリマインダーリストへ同期します。設定した時刻になるとシステムが通知を発火します。緑をタップ:リマインダーから削除。

⚠ DynamicTask 内で ToDo を削除すると、対応するシステムのリマインダーも連動削除されます(片方を消せば両方消える);予定時刻をクリアすると自動で同期解除されます。

iCloud 同期

初回起動時に自動的に有効化されます(ダイアログなし)。すべてのデータ(次元/目標/計画/ToDo/ひらめき)は、あなたのプライベート iCloud データベースを介してデバイス間で同期されます。競合戦略:最後の書き込みが勝つ。iPhone が iCloud にサインインし、iCloud Drive が有効であれば、追加設定なしで動作します。

ウィジェット(ホーム画面)

連続記録のヒートマップ:統計ページの streak と同じビューを、小 / 中 / 大の 3 サイズで提供します。ホーム画面を長押し → ウィジェットを追加 → 「DynamicTask」を検索。

Live Activity(Dynamic Island + ロック画面)

2 つのモードを自動で切り替えます:

  • ToDo 概要:ポモドーロが動いていないとき、Dynamic Island は最初の未完了 ToDo + 全体の進捗を表示し、ロック画面カードは上位 3 件の未完了 ToDo を表示
  • ポモドーロ:ポモドーロ実行中はカウントダウンと進捗リングを表示

Dynamic Island を長押しすると、フルカードに展開します。

サブスクリプション

4 つのプラン。実際の価格は App Store のリアルタイム表示に従います:

  • 月額

사용 안내

최종 업데이트: 2026-05-20

5분 만에 시작하는 DynamicTask — 핵심 철학, 네 단계 모델, 주요 기능을 살펴봅니다.

또 다른 할 일 목록이 아닙니다

DynamicTask의 핵심 아이디어: 할 일을 평평한 목록에서 네 단계로 이루어진 인생 모델로 격상시킨다.

일반적인 할 일 앱은 '오늘 무엇을 할지'를 적게 하지만, DynamicTask는 다음과 같이 명확하게 정리하도록 돕습니다:

  • 차원 (Dimension): 내 인생은 어떤 축으로 나뉘는가? (아이젠하워 4분면 또는 사용자 정의)
  • 목표 (Goal): 무엇을 달성하고 싶은가? (책 읽기 / 운동 / 악기 배우기)
  • 계획 (Plan): 목표 달성을 위해 어떤 활동이 필요한가? (주 3회 근력 운동)
  • 할 일 (Todo): 오늘의 구체적인 한 걸음은? (벤치프레스 4×8)

이 구조가 있다면, 할 일은 더 이상 작업 더미가 아니라 명확한 인생의 길이 됩니다.

네 단계 설명

1. 차원 (Dimension) — 인생의 기준틀.
아이젠하워 매트릭스 기반의 4가지 기본값: 중요도 높음 / 중요도 낮음 / 긴급도 높음 / 긴급도 낮음. '새 목표' 시트에서 사용자 정의 차원(색상 + 이름 선택)을 추가할 수 있습니다. 각 목표에는 여러 차원을 연결할 수 있습니다.
2. 목표 (Goal) — 달성하고 싶은 일.
예: "건축사 시험 합격", "30권의 책 읽기", "기타로 호텔 캘리포니아 연주하기". 각 목표는 하나의 색상을 연결하며(11가지 프리셋 + 시스템 색상 선택기), 그 색상은 하위 할 일까지 계단식으로 적용됩니다. 차원은 선택사항이며 인생 영역별로 목표를 정리하고 싶을 때 연결합니다. 분류를 원하지 않는 사용자를 위해 '기본 목표'(중요도 높음 + 긴급도 높음 연결)가 기본 제공됩니다.
3. 계획 (Plan) — 목표 달성을 위한 활동.
예: 목표 "30권의 책 읽기"의 계획 = "매월 고전 소설 2권". 각 계획에는 아이콘(800+ 라이브러리에서 선택)과 완료 기준(자유 텍스트)이 있습니다. 계획 자체는 할 일이 아닙니다 — 실제로 하는 일은 계획 아래의 할 일입니다.
4. 할 일 (Todo) — 실행 가능한 단계.
예: "매월 고전 소설 2권" 아래의 할 일 = "『백 년 동안의 고독』 3장". 반드시 계획에 속해야 합니다. 1-4개의 하위 작업을 추가할 수 있고, 예정 시간(시작/종료 시간대, 드래그 가능한 링)을 설정할 수 있습니다. 완료 시 만족스러운 마이크로 애니메이션이 재생됩니다.

주요 화면

홈 (할 일)

하단 캡슐 내비게이션의 첫 번째 탭, 기본 진입점. 오늘의 할 일은 고정 → 진행 중 → 완료 세 섹션으로 그룹화됩니다.

  • 아래로 스와이프: 목록 → 주간 캘린더 → 월간 캘린더 순으로 전환
  • 좌측 상단 캘린더 아이콘: 동일한 세 상태를 탭으로 순환
  • 과거 날짜 규칙: 어제 이전의 미완료 할 일은 자동으로 오늘로 이동; 과거 날짜에서는 완료된 항목만 표시
  • 행 상호작용: 행 탭 → 편집 시트; 링 탭 → 완료 표시; 길게 눌러 드래그 → 정렬, 동시에 캡슐이 '고정 / 삭제' 영역으로 변형

각 캘린더 날짜 아래에 1-3개의 색상 점이 그날의 주요 할 일을 표시합니다(설정에서 끌 수 있음).

계획

두 번째 탭. 상단의 가로 탭에 모든 목표가 나열되며 끝에 +로 새 목표를 추가합니다. 목표를 선택하면 아래에 해당 목표의 모든 계획이 표시됩니다(아이콘 + 계획 이름 + 완료 기준). 계획을 길게 누르면 편집 / 삭제 메뉴가 나타납니다.

통계

세 번째 탭. 연속 기록 히트맵(GitHub contributions 스타일) + 목표별 진행 카드(주간/월간 활동). 우측 상단 →로 영감 페이지에 진입 — 아직 정식 목표로 정하지 않은 아이디어로, 정식 목표로 승격할 수 있습니다.

설정

네 번째 탭. 테마 / 강조색 / 뽀모도로 시간 / Dynamic Island 스위치 / iCloud 동기화 상태 / 구독 / 언어 / 도움말 / 피드백 / 홍보 제휴 / 공유 / 별점 매기기.

뽀모도로

다섯 번째 탭(특수). 탭해도 페이지가 전환되지 않고, 현재 페이지 위에 겹쳐서 표시됩니다. 중앙: 큰 카운트다운. 상단: 두 개의 pill로 집중 / 휴식 전환(기본 45 / 5분, 설정에서 변경 가능). 하단: ▶ 시작 / ⏸ 일시정지 / ↻ 재설정. Dynamic Island는 카운트다운과 진행 링을 동기화하여 표시하고, 잠금 화면에도 뽀모도로 카드가 표시됩니다. 세션 동안 하단 캡슐은 뒤로가기 버튼으로 변형됩니다.

주요 기능

iOS 미리 알림과 동기화

할 일 시간 섹션의 오른쪽에는 다색 캘린더 아이콘(calendar.badge)이 있습니다: 회색 점 = 미동기화; 녹색 점 = 동기화됨. 회색을 탭: 처음에는 권한을 요청하고, 권한이 부여되면 현재 할 일을 시스템의 기본 미리 알림 목록에 즉시 동기화합니다. 예정된 시간에 시스템이 알림을 발송합니다. 녹색을 탭: 미리 알림에서 제거합니다.

⚠ DynamicTask 내에서 할 일을 삭제하면 해당하는 시스템 미리 알림도 연쇄적으로 삭제됩니다(한 쪽에서 지우면 양쪽 모두 사라짐); 예정 시간을 지우면 자동으로 동기화가 해제됩니다.

iCloud 동기화

첫 실행 시 자동으로 활성화됩니다(별도 안내 없음). 모든 데이터(차원/목표/계획/할 일/영감)는 본인의 비공개 iCloud 데이터베이스를 통해 기기 간에 동기화됩니다. 충돌 정책: 마지막 쓰기 우선. iPhone이 iCloud에 로그인되어 있고 iCloud Drive가 활성화되어 있으면 추가 설정 없이 작동합니다.

위젯(홈 화면)

연속 기록 히트맵: 통계 페이지의 streak와 동일한 보기로, 소 / 중 / 대 세 가지 크기로 제공됩니다. 홈 화면을 길게 누름 → 위젯 추가 → 'DynamicTask' 검색.

Live Activity (Dynamic Island + 잠금 화면)

두 모드 사이를 자동으로 전환합니다:

  • 할 일 개요: 뽀모도로가 실행 중이 아닐 때, Dynamic Island는 첫 번째 미완료 할 일 + 전체 진행 상황을 표시하고, 잠금 화면 카드는 상위 3개의 미완료 할 일을 표시합니다.
  • 뽀모도로: 뽀모도로 세션 중에는 카운트다운과 진행 링을 표시합니다.

Dynamic Island를 길게 누르면 전체 카드로 확장됩니다.

구독

네 가지 등급. 실제 가격은 App Store가 실시간으로 표시합니다:

  • 체험 회원: 7일 무료 체험, 만료 시 자동으로 월간으로 전환
  • 월간
  • 연간: 월간보다 가성비 우수
  • 평생 구입: 향후 모든 새 기능 포함, 구독과 기능 동일(기간만 다름, '인기' 배지 부여)

세 가지 유료 등급(월간 / 연간 / 평생)은 기능이 동일하며, 기간만 다릅니다. 월간과 연간은 동일한 Subscription Group에 속하므로 iOS 구독 설정에서 자유롭게 업그레이드/다운그레이드할 수 있습니다(Apple이 자동으로 비례 환불). 체험 자격은 Apple ID별로 판단되며, 각 Apple ID는 Subscription Group당 한 번만 사용할 수 있습니다. 시스템 설정 → Apple ID → 구독 에서 언제든지 취소 가능; 체험 기간 중 취소하면 요금이 청구되지 않습니다.

기기 변경 / 앱 재설치 후: 설정 → 구독 시작 → 구입 복원으로 모든 과거 구입 항목을 복원할 수 있습니다.

개인정보 보호

Nicht noch eine To-do-Liste

Die Kernidee von DynamicTask: Ihre To-dos von einer flachen Liste zu einem vierstufigen Lebensmodell aufwerten.

Gewöhnliche To-do-Apps lassen Sie aufschreiben, „was heute zu tun ist"; DynamicTask fordert Sie auf, klar zu denken:

  • Dimension: Wie ist Ihr Leben unterteilt? (Eisenhower-Matrix oder individuell)
  • Ziel (Goal): Was möchten Sie erreichen? (Bücher lesen / Fit werden / Ein Instrument lernen)
  • Plan: Welche Aktivitäten sind zur Zielerreichung nötig? (3× Krafttraining pro Woche)
  • To-do: Welcher konkrete Schritt heute? (Bankdrücken 4×8)

Mit dieser Struktur sind Ihre To-dos kein Aufgabenhaufen mehr, sondern bilden einen klaren Lebensweg.

Die vier Ebenen im Detail

1. Dimension — Bezugsrahmen Ihres Lebens.
Vier Standardwerte basierend auf der Eisenhower-Matrix: Hohe Wichtigkeit / Geringe Wichtigkeit / Hohe Dringlichkeit / Geringe Dringlichkeit. Eigene Dimensionen (Farbe + Name) lassen sich über die „Neues Ziel"-Ansicht hinzufügen. Jedes Ziel kann an mehrere Dimensionen gebunden werden.
2. Ziel (Goal) — was Sie erreichen möchten.
Beispiele: „Architekturprüfung bestehen", „30 Bücher lesen", „Hotel California auf der Gitarre lernen". Jedes Ziel ist an eine Farbe gebunden (11 Voreinstellungen + Systemfarbwähler), die sich kaskadiert auf die zugehörigen To-dos überträgt. Dimensionen sind optional — binden Sie sie, um Ziele nach Lebensbereich zu ordnen. Für Nutzer, die nicht kategorisieren möchten, ist ein „Standardziel" (mit Hoher Wichtigkeit + Hoher Dringlichkeit) bereits angelegt.
3. Plan — Aktivitäten zur Zielerreichung.
Beispiel: Unter dem Ziel „30 Bücher lesen" lautet ein Plan = „2 klassische Romane pro Monat". Jeder Plan hat ein Symbol (aus 800+ Bibliothek) und ein Erfüllungskriterium (Freitext). Ein Plan ist selbst kein To-do — Sie „erledigen" den Plan nicht, sondern die darunter liegenden To-dos.
4. To-do — umsetzbare Schritte.
Beispiel: Unter „2 klassische Romane pro Monat" lautet ein To-do = „‚Hundert Jahre Einsamkeit', Kapitel 3". Muss zu einem Plan gehören. Kann 1–4 Teilaufgaben haben; kann eine geplante Zeit (Start-/Endfenster, ziehbarer Ring) haben. Beim Abschluss wird eine angenehme Mikroanimation abgespielt.

Hauptansichten

Start (To-dos)

Erste Schaltfläche in der unteren Kapsel-Navigation, Standardeinstieg. Die heutigen To-dos sind in drei Gruppen unterteilt: Angeheftet → In Bearbeitung → Erledigt.

  • Pull-Down-Geste: zwischen Liste → Wochenkalender → Monatskalender wechseln
  • Kalendersymbol oben links: tippen, um dieselben drei Zustände zu durchlaufen
  • Regel für vergangene Termine: gestern und früher offene To-dos werden automatisch auf heute verschoben; an vergangenen Daten werden nur erledigte angezeigt
  • Zeileninteraktionen: Zeile antippen → Bearbeitungs-Sheet; Ring antippen → als erledigt markieren; Lange drücken und ziehen → neu ordnen, die Kapsel verwandelt sich in „Anheften / Löschen"-Zonen

Unter jedem Kalendertag markieren 1–3 farbige Punkte die wichtigsten To-dos des Tages (in den Einstellungen abschaltbar).

Ziele

Zweite Schaltfläche. Horizontale Tabs oben listen alle Ziele auf, mit einem nachfolgenden + für neue Ziele. Wenn Sie ein Ziel auswählen, erscheinen darunter dessen Pläne (Symbol + Planname + Erfüllungskriterium). Plan lange drücken, um zu bearbeiten / löschen.

Statistik

Dritte Schaltfläche. Streak-Heatmap (im Stil von GitHub-Contributions) + Fortschrittskarten pro Ziel (Wochen-/Monatsaktivität). Oben rechts öffnet → die Inspirationen — Ideen, die Sie noch nicht formal festgelegt haben; lassen sich zu echten Zielen befördern.

Einstellungen

Pomodoro

Fünfte Schaltfläche (Sonderfall). Tippen wechselt nicht die Seite, sondern legt eine Schicht über die aktuelle Seite. Mitte: großer Countdown. Oben: zwei Pills zum Umschalten zwischen Fokus / Pause (Standard 45 / 5 Min., konfigurierbar). Unten: ▶ Start / ⏸ Pause / ↻ Zurücksetzen. Die Dynamic Island spiegelt Countdown und Fortschrittsring; auch der Sperrbildschirm zeigt eine Pomodoro-Karte. Während einer Sitzung verwandelt sich die untere Kapsel in eine Zurück-Schaltfläche.

Pas une énième liste de tâches

L'idée fondatrice de DynamicTask : faire passer vos tâches d'une liste plate à un modèle de vie à quatre niveaux.

Касание серой: при первом разе будет запрошено разрешение; затем текущая задача сразу синхронизируется в стандартный список «Напоминания». Система отправит уведомление в назначенное время. Касание зелёной: удаляет из «Напоминаний».

⚠ Удаление задачи в DynamicTask каскадно удаляет соответствующее системное напоминание (одно удаление очищает обе стороны); удаление запланированного времени автоматически отменяет синхронизацию.

Синхронизация iCloud

Включается автоматически при первом запуске (без диалогов). Все данные (измерения / цели / планы / задачи / идеи) синхронизируются между устройствами через вашу частную базу данных iCloud. Стратегия конфликтов: выигрывает последняя запись. Работает, пока ваш iPhone авторизован в iCloud, а iCloud Drive включён, — никакой дополнительной настройки.

Виджет (экран «Домой»)

Тепловая карта серии: то же представление, что и на странице «Статистика», доступно в размерах малый / средний / большой. Удерживайте экран «Домой» → Добавить виджет → найдите «DynamicTask».

Live Activity (Dynamic Island + экран блокировки)

Автоматически переключается между двумя режимами:

  • Обзор задач: когда Pomodoro не запущен, Dynamic Island показывает первую незавершённую задачу + общий прогресс; карточка на экране блокировки показывает 3 первых незавершённых задач
  • Pomodoro: во время сессии Pomodoro показывает обратный отсчёт и кольцо прогресса

Удерживайте Dynamic Island, чтобы развернуть полную карточку.

Подписка

Четыре уровня. Реальные цены App Store показывает в режиме реального времени:

  • Пробный участник: 7-дневная бесплатная пробная версия; по истечении автоматически переходит на ежемесячную
  • Ежемесячная
  • Годовая: выгоднее ежемесячной
  • Пожизненная: включает все будущие функции, идентична подпискам, отличается только сроком (значок «Лучшее предложение»)

Три платных уровня (ежемесячная / годовая / пожизненная) предоставляют одинаковый набор функций — отличается только срок. Ежемесячная и годовая принадлежат одной Subscription Group, поэтому в настройках подписок iOS вы можете свободно повышать/понижать уровень (Apple автоматически делает пропорциональный возврат). Право на пробный период определяется по Apple ID; каждый Apple ID может использовать пробу один раз на Subscription Group. Отменить подписку можно в любой момент через Системные настройки → Apple ID → Подписки; отмена в пробный период бесплатна.

После смены устройства / переустановки: Настройки → Подписка → Восстановить покупки вернёт все прежние покупки.

Конфиденциальность

DynamicTask не собирает никаких пользовательских данных на наших серверах. Все данные хранятся локально и синхронизируются через вашу частную базу данных iCloud; видеть их можете только вы и Apple. Подробнее в Политике конфиденциальности.
